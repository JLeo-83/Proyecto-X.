# 🚀 ThreeJS Portfolio – React + Vite

Portafolio interactivo desarrollado con **React**, **Vite** y **Three.js**, con animaciones avanzadas y renderizado 3D en tiempo real.

🌐 **Demo en vivo:**
👉 [https://proyectotree.netlify.app](https://proyectotree.netlify.app)

---

## 🛠️ Tecnologías utilizadas

* ⚛️ React 18
* ⚡ Vite 5
* 🎨 TailwindCSS
* 🌌 Three.js
* 🧩 @react-three/fiber
* 🎬 GSAP
* 📩 EmailJS

---

## 📦 Instalación

Clona el repositorio:

```bash
git clone https://github.com/JLeo-83/Proyecto_X.git
```

Entra en la carpeta del proyecto:

```bash
cd Proyecto_X
```

Instala las dependencias:

```bash
npm install
```

---

## 💻 Desarrollo

Ejecuta el servidor local:

```bash
npm run dev
```

Luego abre en tu navegador:

```
http://localhost:5173
```

---

## 🏗️ Build para producción

Para generar la versión optimizada:

```bash
npm run build
```

El proyecto final se generará en la carpeta:

```
dist/
```

Para previsualizar el build:

```bash
npm run preview
```

---

## 🌍 Deploy en Netlify

Configuración recomendada:

| Campo             | Valor           |
| ----------------- | --------------- |
| Build command     | `npm run build` |
| Publish directory | `dist`          |
